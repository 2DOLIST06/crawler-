Mission : Parameter URLs SEO Audit

Objectif

Auditer les URLs avec paramètres (tracking, pagination, filtres, tri, réservation) pour détecter les risques SEO sans modifier le site.

Vérifications

  • Détection des URLs contenant ? depuis les liens, canonical, hreflang, prev/next et sitemap.
  • Contrôle sitemap : URL paramétrée présente = erreur.
  • Contrôle canonical/robots pour tracking, pagination, filtres et tri.
  • Classification des paramètres : tracking, pagination, filter, sorting_display, booking_or_availability, unknown.
  • Génération limitée de variantes de test (cap configurable).

Exports

  • parameter_urls_seo_audit.json
  • parameter_urls_seo_audit.csv
