Mission : SEO Technical Audit

A. Ce que la mission crawle

  • Page d'accueil.
  • URLs internes trouvées dans les liens <a href="">.
  • URLs du sitemap.
  • Canonical.
  • Hreflang.
  • Prev / next.
  • URLs internes uniquement.
  • Pas de formulaires.
  • Pas de clics JS.
  • Pas d'actions de réservation.

B. Ce que la mission ignore

  • Domaines externes.
  • Images CloudFront comme pages à crawler.
  • Fichiers JS/CSS/images comme pages.
  • mailto:
  • tel:
  • javascript:
  • data:
  • Fragments #...
  • Paramètres de tracking.

E. Comment lire le rapport

  • Le résumé donne l'état global du site et les signaux majeurs du run.
  • Les corrections prioritaires indiquent quoi corriger en premier pour maximiser l'impact SEO.
  • La section URLs anglaises indique où les slugs anglais sont trouvés.
  • La colonne « Où corriger ? » indique si le problème vient du code, du contenu, du sitemap, des redirections, canonical ou hreflang.
  • Les exports servent à travailler les corrections hors interface (tri, assignation, suivi).

F. Réglages conseillés

Premier test :

  • Max pages : 100
  • Profondeur : 3
  • Mode : HTTP
  • Respect robots.txt : non

Audit plus large :

  • Max pages : 1000
  • Profondeur : 5
  • Mode : HTTP
  • Respect robots.txt : non

Audit rendu JS :

  • Mode : browser
  • Max pages plus faible
  • À utiliser si des liens ne sont visibles qu'après rendu JavaScript
