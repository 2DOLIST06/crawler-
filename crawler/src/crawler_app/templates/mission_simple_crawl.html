Mission : Crawl simple

Ce que la mission crawle

  • La page d'entrée et les URLs internes découvertes via les liens HTML standards.
  • Les pages accessibles en mode HTTP ou browser selon la configuration du run.

Ce qu'elle extrait

  • Statut HTTP, URL finale, profondeur, canonical.
  • Titre, meta description, nombre de H1.
  • Volumes de liens internes et externes, ressources détectées.

Ce qu'elle ignore

  • Les actions utilisateur (formulaires, clics applicatifs, tunnels de réservation).
  • Les scénarios JavaScript complexes non accessibles sans interaction.
  • L'audit SEO avancé multi-modules (sitemap/hreflang/pagination détaillée).

Exports générés

  • pages.csv / pages.json
  • links.csv / links.json
  • resources.csv / resources.json
  • full.json

Réglages conseillés

  • Premier passage : 100 pages, profondeur 3, mode HTTP.
  • Site plus large : 300 à 1000 pages, profondeur 4 à 5.
  • Activer le mode browser si une partie du maillage n'apparaît qu'après rendu JavaScript.
